# All-in-One Job Scraper (Upwork, LinkedIn, Simplify)

Extract high-paying leads instantly across Upwork, LinkedIn, and Simplify simultaneously using custom budget filters! 

### ⚡ Key Features
* **Multi-Platform Support:** Scan Upwork, LinkedIn, and Simplify simultaneously or individually.
* **Precise Budget Controls:** Filter by exact minimum and maximum rates (e.g., $100 - $5,000+).
* **Automated Data Extraction:** Collects roles, location data, company names, budgets, and application links.
* **Smart Commitment Filters:** Automatically tags positions as Full-time, Part-time, or Contract.
* **Flexible Export Options:** Download curated job leads instantly in JSON, CSV, or Excel formats.

### 🛠️ How to Use
1. Enter your target **Search Keyword** (e.g., *React Developer, UI Designer*).
2. Choose your target **Platform** or select **All Platforms** for a master sweep.
3. Set your **Minimum Budget** (e.g., `5000` to find high-ticket clients).
4. Click **Start** and download your curated hot leads in CSV or Excel format.
